# Setup

1. Create a PUBLIC repository named exactly `amirazadii` under the `amirazadii` account.
2. Put `README.md` in the repository root.
3. Put `snake.yml` at `.github/workflows/snake.yml`.
4. Commit and push both files.
5. Open the repository's **Actions** tab and run **Generate Contribution Snake** once using **Run workflow**.
6. After the workflow creates the `output` branch, refresh your GitHub profile.
7. Pin your strongest public repositories from **Customize your pins** on your profile.
8. Optional: uncomment the LinkedIn badge in README.md and replace the placeholder with your real URL.

GitHub displays a profile README when the repository is public, its name exactly matches the username, and README.md exists in the root.
